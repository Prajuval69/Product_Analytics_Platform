# Project Specification

## Project name
Product Analytics & Data Modelling Platform

## Goal
Demonstrate an end-to-end analytics engineering and product analytics workflow using synthetic SaaS/product data.

## Primary personas
- Product manager: wants funnel, retention and feature adoption insights.
- Growth analyst: wants acquisition-to-conversion analysis.
- Data analyst: wants trusted KPI tables.
- Data engineer/analytics engineer: wants reliable orchestration and transformations.
- ML analyst: wants churn-risk scoring.

## Minimum analytical questions
1. How many users are active daily, weekly and monthly?
2. Where do users drop out of onboarding/product funnels?
3. Which features have the highest adoption?
4. How does retention differ by signup cohort?
5. Which customer segments have elevated churn risk?
6. How does product engagement relate to revenue?
7. Which subscription/product segments generate the most revenue?
8. Are reporting datasets fresh and valid?

## Acceptance criteria
- Complete runnable repository.
- PostgreSQL raw layer.
- Real dbt transformations.
- Real Airflow DAG.
- Dimensional model.
- Product analytics marts.
- Churn ML workflow.
- Automated tests.
- BI exports.
- Complete documentation.
